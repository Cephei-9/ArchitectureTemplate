# ArchitectureTemplate

Шаблон архитектуры Unity-проекта с упором на понятную композицию модулей приложения, инициализации и инфраструктурных сервисов.

## Сервисы

Сервисы в проекте выступают как точки доступа к модулям.
Они дают единый и понятный API для работы с системой из любого места проекта, скрывая детали конкретной реализации.
Так модуль можно развивать или заменять без переписывания кода, который им пользуется.

## Пайплайн инициализации

Инициализация построена как асинхронный пайплайн из последовательных шагов.
Такой подход позволяет явно настраивать порядок запуска, проще читать стартовый сценарий приложения и безопасно добавлять новые этапы.
В будущем каждая платформа сможет собирать и настраивать свой собственный пайплайн инициализации под свои требования.

## Asset Management

В проекте есть отдельный слой asset management с реализацией на Addressables.
Он дает удобный способ работать с ассетами по ключу: загружать, получать, инстанцировать и выгружать их из любого места проекта.
Поддерживается работа как с одиночными ассетами, так и с массовой загрузкой и выгрузкой групп ассетов.

## UI Framework

UI в проекте построен на подходе PresentationModel с реактивностью.
View ничего не решает и не хранит логику: она просто читает состояние PresentationModel и отображает его.
Для окон сделана удобная инфраструктура открытия и закрытия, а также размещения UI на разных слоях.
В результате UI-фреймворк дает простой, понятный и удобный интерфейс для повседневной работы с экранами, окнами и попапами.
